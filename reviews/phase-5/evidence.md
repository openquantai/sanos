# Phase 5 implementation evidence

Date: 2026-10-12

## Scope

Phase 5 implements reference-compatible daily WIDB pairing and enrichment as
two immutable Intermediate artifacts. It uses the Phase 2 artifact store and
runner and never opens WRDS. The six direct Raw inputs are security, options,
current spot, previous-session spot, current forwards, and current zero curve.

Each stage persists one `data.parquet` frame plus portable configuration and
descriptive metadata. `paired-day` keeps the exact reference cleaning/join
order. `enriched-day` projects the discounted forward, forms the blended call
book, converts to pure units, inverts volatility, and appends Greeks/NMS.

## Compatibility controls

- `overnight_variance_fraction=0.2` is canonical and versioned; AM subtraction
  is `1-fraction`; PM is unchanged.
- Known-bad dates retain typed-empty behavior. The latest-supported-date cutoff
  remains fatal.
- Zero business DTE is accepted only for the historical Saturday-AM pattern.
- Implied-volatility errors above tolerance must occur at a configured boundary
  before the affected row can be removed.
- Float32 frame boundaries and reference filter ordering are retained. A
  checked-in synthetic oracle generated by the pinned reference freezes every
  ordered enriched Float32 vector by SHA-256 and the legacy Float32-first spot
  return.
- Exclusion registries, schema policies, clock/NMS values, Black adapters, and
  IV/Greek tolerances participate in resolved producer versions.
- CD-020 records a proposed future repair: the pinned reference accidentally
  fails an all-valid day because it retains its internal `is_valid` column.
  The initial migration preserves that failure explicitly until approved.
- CD-003, CD-016, CD-017, CD-018, and CD-019 document deliberately preserved
  ambiguities/no-ops rather than silently changing them.

## Human/automation interface

```text
sanos intermediate build --config configs/widb-spx-reference.json \
  --ticker SPX --start-date 2022-01-03 --end-date 2025-08-29 \
  --through enriched-day --exclude-half-days --max-workers 4
```

The command has text/JSON output, global dry-run and verbose controls, bounded
spawn workers, restart journals, output-first reuse, and reuse-only
`--version '*'`. A terminal hit does not require Raw ancestors to remain.
